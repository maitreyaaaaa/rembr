## Defects, risks, and next steps

- Semantic retrieval is an agreed Phase 4 capability and remains unimplemented in production. Resume after selecting a provider/storage approach or explicitly revising its scope; then implement consent, usage controls, indexing lifecycle, owner-scoped persistence/query, API/UI states, and provider failure behavior.
- The hosted migration history repair remains pending. Mark the nine alternate hosted version IDs reverted and their nine local filename versions applied, then verify the ledger. The user has authorized the three pending schema migrations; apply them afterward in order and verify the schema plus consent/job effects. One migration cancels eligible nonconsented queued/paused analysis jobs and invalidates older consent; another requires grounded-search consent v5; the newest adds an off-by-default visual-search consent table with RLS. The Supabase plugin can apply new migrations but cannot perform the history-only repair, and an API token alone does not provide the direct database URL required by the pinned CLI command.
- A fresh Phase 3 source audit found a media-acquisition parity gap beyond the deferred API-key checks: the current Instagram resolver handles one HTML-exposed MP4 but ignores standalone audio URLs, skips non-MP4 video, and does not use IScraper's post/reel downloader. The user directed that this remains Phase 3 work; do not implement that parity in this Phase 4 pass. Phase 4 OCR/ASR coverage is limited to currently supported media paths and remains dependent on closing the Phase 3 gap.
- Obtain representative human-reviewed owner-local qrels before making retrieval-quality claims. Keep them out of the repository.
- Keep the user's browser/accessibility confirmation marked as reported evidence; add exact routes/viewports or screenshots if those are needed for a reproducible review record.
- The Phase 4 exit gate from [`phase-gated-roadmap.md`](phase-gated-roadmap.md#phase-4--search-knowledge-and-optional-ai) remains **open**: all agreed search/knowledge features are not yet proven complete.
