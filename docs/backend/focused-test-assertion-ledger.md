# Focused backend test assertion ledger

This is the central cross-supplement index for assertion-level reads of the 37 orchestration test files. Every test source was read in full; detailed maps are split into this file, `api-test-assertion-audit.md`, `test-audit-supplement-small.md`, `test-audit-supplement-queue-runtime.md`, and `test-audit-supplement-stores-billing.md`. No test command was run. Assertions describe intended behavior, not production guarantees.
